# 把程序烧录到小车（StampC3）

## 先弄清楚烧的是什么

- 小车上我们能编程的只有顶上那块 **M5StampC3**，跑的是 Arduino（C++）程序。下面的 Pololu 3Pi+ 底盘出厂已带固件和中间件，**不需要也不能**由我们烧录。
- 一个 Arduino 程序叫一个“草图”（sketch），就是一个文件夹：一个 `.ino` 主文件，加同目录下所有 `.cpp`/`.h`（`Controller`、`Robot`、`RobotWifiAP`、`TaskTimer`、`OdometryModel`、`RobotIMU`、`i2c_datatypes.h`）。**整个文件夹一起编译、一起烧录**，不是单独烧某个文件。文件夹名必须和 `.ino` 文件名相同。
- **本仓库的 `robot/MyRobot` 就是我们小车现在跑的草图**（课程模板 + 我们改过的 `Controller.cpp` 和 `.ino`）。下载仓库后用 Arduino IDE 打开 `robot/MyRobot/MyRobot.ino` 即可烧录。`.ino` 里的 WiFi 名和密码只用来区分各组的小车，换车时改成自己的。
- 课程原始草图在课程仓库 https://github.com/paulodowd/RoboticsScienceAndSystems 的 `StampC3_Template`。平时改的是 `Controller.cpp`/`Controller.h`（行为和参数）以及 `.ino`（队名、WiFi）。
- **本仓库的 `simulation/` 是电脑上运行的 Processing 停车仿真（Java），不能烧录到小车上。** 停车控制器目前只在仿真里，还没有移植成 StampC3 的 C++ 代码。

## 一次性准备（每台电脑做一次）

1. 安装 **Arduino IDE 2**。
2. `File → Preferences → Additional boards manager URLs` 填入：
   `https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json`
3. `Tools → Board → Boards Manager`，搜索 **M5Stack**，安装（我们这台用的是 3.3.9）。
4. 用**能传数据**的 USB-C 线连接 StampC3（有些线只能充电）。Windows 设备管理器的“端口”里应出现 `USB-Enhanced-SERIAL CH9102 (COMx)`。没有的话安装 WCH 的 CH9102/CH343 驱动，或换线、换口。

## 每次烧录

1. 用 Arduino IDE 打开草图文件夹里的 `.ino`。
2. 菜单设置（一个都不能错）：

   | 菜单 | 选择 |
   | --- | --- |
   | Tools → Board | M5Stack → **M5StampC3** |
   | Tools → Port | **COMx（CH9102）**，不是蓝牙的 COM 口 |
   | Tools → USB CDC On Boot | **Disabled**（默认是 Enabled；不改的话串口监视器看不到输出） |
   | Tools → Upload Speed | 921600（失败就改 115200） |

3. 检查 `.ino` 里的两处：
   - `robot.initialise("队名");`：课程中间件按这个名字配置（不超过31字符）。不带名字的 `robot.initialise();` 会关闭中间件，只用于对照实验。
   - `RobotWifiAP_c server("WiFi名", "WiFi密码", 80);`：小车自己的 WiFi 热点，用来区分各组的小车，每台车各设各的。
4. 点 ✓（Verify）编译，再点 →（Upload）上传。成功时输出末尾是 `Hash of data verified.` 和 `Hard resetting via RTS pin...`。
5. `Tools → Serial Monitor`，波特率 **115200**。每50毫秒一行遥测：

   `时间ms, x, y, θ, 左PWM, 右PWM, 左编码器, 右编码器, DN1, DN2, DN3, DN4, DN5, signal`

   最后一列 `signal=0` 表示在等按钮。按一下 StampC3 上的按钮才开始运行控制器。

**安全**：调试新程序时把小车**翻过来让轮子悬空**；不要用手按住通电的轮子（会打坏齿轮）；高 PWM 不要长时间运行（电机会过热）。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 端口列表里没有 COMx | 换数据线或 USB 口；装 CH9102 驱动；看设备管理器 |
| `Board at COMx is not available` | USB 没插好或选错口；关掉占用串口的程序（串口监视器、Processing、PuTTY） |
| 上传成功但串口监视器没输出 | USB CDC On Boot 没设成 Disabled，改后重新上传；波特率要 115200；按一下按钮 |
| 上传中途失败 | Upload Speed 改 115200 再试 |

## 命令行方式（可选，本机已配置）

本机工具在 `E:\SEMTM0043\tools`，也可以双击 `E:\SEMTM0043\Start Arduino IDE.cmd` 用同一套配置打开 IDE。命令行等价于上面的 IDE 操作（PowerShell）：

```powershell
$env:ARDUINO_CONFIG_FILE = 'E:\SEMTM0043\tools\arduino-cli.yaml'
$cli  = 'E:\SEMTM0043\tools\arduino-cli\arduino-cli.exe'
$fqbn = 'm5stack:esp32:m5stack_stamp_c3:CDCOnBoot=default'   # CDCOnBoot=default 即 Disabled
& $cli compile --fqbn $fqbn .\robot\MyRobot
& $cli upload  -p COM5 --fqbn $fqbn .\robot\MyRobot
& $cli monitor -p COM5 -c baudrate=115200
```

2026-10-30 在本机实测：`MyRobot` 编译通过（程序占76%），上传到 COM5 后校验通过，串口每50毫秒输出遥测，signal=0 等待按钮。
