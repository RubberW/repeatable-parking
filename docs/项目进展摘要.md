# 项目进展摘要（截至 2026-10-30）

SEMTM0043/42 Robotics Science & Systems，小组项目选题“重复停车（Repeatable Parking）”。三人各负责一个子系统：电机（本仓库作者）、反射率传感器、里程计。

课程分两阶段：**Phase 1（个人）**用实体机器人测试并刻画自己负责的子系统；**Phase 2（小组）**把测到的特性写进数字孪生仿真，用选定任务比较仿真与实物的差异并批判性分析。本仓库目前的停车仿真属于 Phase 2 任务的准备和延伸研究，**不是** Phase 1 的要求；Phase 1 电机刻画见文末“新方向”。

## 1. 系统思路（源代码怎么组织）

任务：小车从未知起点出发，在只知道停车标记图案、不知道场地尺寸和起点的情况下，找到黑色停车框并停进去（中心余量≥5毫米、航向±5°、静止≥1秒，由独立验收按真实位姿判定）。

```
传感器(5路反射率) + 编码器
        │
 ParkingCore（总调度）
   ├─ 未见黑框：CompactSearch 探索
   │     ├─ 探索主模型 heading_seed4（小网络，32个动作=16方向×400/1000毫米）
   │     ├─ SearchMemory：走过的格子、灰色桌边格、直边拟合、检测覆盖
   │     ├─ SearchDecision：主模型打分 − 8×“该方向检测带已搜比例”
   │     ├─ HeadingGate：触边后方向约束（边线可靠→朝内即可；不可靠→留在桌内证据内）
   │     └─ BoundaryMotion：触边动作（刹车→离边70毫米→原地转向→沿主模型方向出发）
   └─ 见到黑框：early_fit 局部停车
         ├─ ParkingFrameProbe：沿框线追踪，收集黑白点
         ├─ Localizer：把黑白点与已知图案做相关匹配，得到临时拟合
         ├─ 直接停车（默认）：直接开到停车点，沿途核对、跳变对齐修正、停车位姿五路特征
         └─ 证据不足时退回：入口(两端自适应) → 读三条不等宽方向条纹 → 需要时横扫中线 → 停车点
```

关键设计原则：
- **控制器只用传感器和编码器**，真实地图、真实位姿只给仿真环境和独立验收（`SupportRisk`、`independentlyParked`）。
- **新行为一律先做成开关**，默认值必须逐行复现参考结果；所有开关集中在 `configs/CURRENT_SEARCH.json`，`SimulationRunner` 和 `scripts/verify.py` 读同一份。
- **实验协议**：只在单独生成的调参场景上选参数，选择规则事先写定；最终用从未使用过的场景确认；按场景配对比较。

文件级分工见 [代码分工.md](代码分工.md)，每版实验记录见 [search_coverage_20261030/README.md](../experiments/results/search_coverage_20261030/README.md)。

## 3. 试过并否决的

| 做法 | 否决原因 |
| --- | --- |
| 只把完全重合（70毫米内）当重复路径 | 看不出隔一百多毫米的平行线也是重复（“两根筷子”），主要问题出在选目标 |
| 原凸包方向约束（子目标终点须在最近800毫米路径凸包内） | 直线撞边时只剩约64毫米宽窄带，几乎只能原路返回 |
| 证据层终点不受限 / 只留8毫米边距 | 贴边越线；改为终点在证据内且离边60毫米 |
| 局部触边线截断、按不确定性加大余量（单独使用） | 对浅角度越线无效，真正原因是证据层允许终点出界 |
| 触边后就地原地转（原动作） | 中心离边仅20～45毫米，轮子画圆必扫出边线 |
| safe_mm=90 / 110 | 越线略少但慢约11%，按事先规则选70 |
| 固定入口点 (0,−115) | 框靠边时站不进去会无限重试；后被自适应入口、再被直接停车取代 |
| 直接停车用全部黑白点精修拟合 | 旧点带里程计航向漂移，最终航向误差到5°，调参集2次误报停车 |
| 只用拟合后的黑白点精修 | 黑白点对航向约束太弱，仍到3.9°、3次误报；改用跳变位置 |
| 以未匹配跳变比例作为拒绝条件 | 正确拟合也常有十几个未匹配跳变，不能区分对错 |
| 早期的神经网络循迹研究计划 | 与当前选题无关，属历史方案 |

## 4. 尚未解决或待考证

- **刹车惯性越线**：每次触边仍约0.25秒轮子越线。传感器只在车心前约45毫米，发现灰色时车轮已接近边线；这直接取决于电机制动特性（见新方向）。
- **对里程计的依赖**：倒车只走“走过的格子”、离边距离、4米证据范围、直接停车的跳变对齐都靠里程计。仿真里8米仅约4毫米误差，实物未知。
- **阈值来自干净的二值读数**：6毫米/3毫米黑白矛盾阈值、跳变时刻都假设传感器读数清楚；实物灰度噪声、光斑大小、光照变化未建模。
- **仿真的电机模型是理想线性**：`MotorsModel.pde` 把PWM线性映射到轮速，没有死区、饱和、左右不对称、噪声；`WheelDynamics.java` 的时间常数和加减速度是假设值。直接停车中曾因“静止时约1 PWM推不动”卡住（已加最小转速），说明死区类效应对停车末段很关键。
- 速度收益随场景集差异大（逐场景几何平均比 0.76～0.97），越线减少稳定。
- 直接停车最终航向误差最大约2°（原条纹校准约1.4°），仍在5°内。
- 自定义（趣味）地图未验证新触边动作；虚拟桌边不模拟真实跌落；**全部未上实车**。

## 5. 新方向

**Phase 1 电机刻画（个人作业，当前重点）**：按课程电机页面的七个练习（指令、编码器测速、死区、饱和、增益响应、非线性、动态），在实物上测并量化：起动/停止死区和左右差异、PWM→轮速曲线与饱和、阶跃响应时间常数和制动距离、同一PWM下左右轮速不对称导致的直线偏航、原地转与差速转弯时的死区影响、低速段（停车末段常用）的可重复性。每项写清研究问题、为什么影响停车、实验设计与对照、怎样判断结果可信。

**Phase 2 数字孪生**：把测到的死区、不对称、时间常数和制动写进 `MotorsModel`/`WheelDynamics`，比较仿真与实物停车的最终位姿，看“仿真里停得进”能否预测“实物停得进”。

**给队友的可能方向（仅建议）**：
- 反射率：不同光照（顶灯、侧光、阴影、日光）和高度/倾角下五路读数分布是否重叠；黑白阈值和灰色桌边判定的鲁棒性；读数随时间的漂移。
- 里程计：曾出现因数值精度截断（小数位丢失）导致误差逐步累积、最终位姿大幅偏离的问题；可量化累积误差随路程的增长、轮径与轮距标定误差、打滑的影响，以及用双精度/整数累计计数的修正效果。
