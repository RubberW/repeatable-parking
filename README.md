# 重复停车：当前自己的代码

双击 **停车控制台.cmd**，直接打开 Processing 停车仿真。也可以用 Processing 打开 `simulation/ParkingSimulation/ParkingSimulation.pde` 并点击运行。

当前只保留一套实现：探索主模型 heading_seed4（权重未变，打分加检测尺度重复扣分）、触边后的方向约束、触框后的 early_fit 停车、按“方向向量”执行的触边动作。旧循迹任务、旧搜索模式、重复源码、多层启动包装和历史交付包已移出项目目录。

## 2026-10-30 起的默认方案

- **重复扣分**：框心离轨迹约110毫米内必被经过，按这一检测宽度判断“已搜过”；主模型打分减去 8×候选方向已搜比例，减少平行贴近的重复路径。
- **方向约束**：触边后不再只能回到最近800毫米走过的窄带；边线拟合可靠时方向朝内（余量随拟合不确定性增大）即可去新区域，不可靠时子目标留在已确认的桌内区域并离边60毫米。
- **触边动作**：刹车→沿走过的路倒车或外侧轮不动转向，直到中心离所有边界证据70毫米→原地转到主模型方向→从新位置沿该方向出发；途中触到新边则重新选择。
- **入口自适应**（`local_parking.adaptive_entry`）：框靠桌边时原固定入口点站不进去会无限重试；现在入口或读条纹途中触边，下次从框另一端进入并镜像读条纹。三组场景中原来的15次局部停车超时全部恢复，其余场景逐步不变。
- **直接停车**（`local_parking.direct_approach`）：识别出框后不去固定入口，直接开到停车点；沿途按拟合预测黑白计数矛盾，用黑白跳变对齐真实墨迹边界修正位置和航向，最后核对五路传感器特征；证据不足退回原入口+条纹验证路线。五组场景共640次：全部停车、0误报，平均局部停车约20.5→12.9秒，最终航向误差最大约2°（原约1.4°）。详见实验记录“直接停车”一节。
- 自定义（趣味）地图未验证新动作，仍用原条件触边动作且不加扣分。

全新128次场景配对（`experiments/data/confirm_scenes_20261101_x2.csv`）：平均找到黑框230→163秒，每次触边轮子越线时间0.83→0.25秒，严重越线1→0；另一组全新128次（`..._20261102_x2.csv`）平均204→179秒（逐场景仅约快3%），越线时间5.65→2.10秒/次运行，严重越线2→0。速度收益随场景差异较大，安全收益稳定。详见[实验记录](experiments/results/search_coverage_20261030/README.md)。原固定64场景：平均找到黑框174→122秒；采用直接停车后局部停车18.9→13.5秒，验收参考改为 `experiments/results/default_20261030_direct/direct_64.csv`（与上一版参考相比只有局部停车的四列变化，搜索阶段逐场景相同）。

`simulation/` 是电脑上运行的停车仿真，不能烧录到小车；小车上现在跑的 StampC3 草图在 `robot/MyRobot`，烧录方法见 [烧录到小车](docs/烧录到小车.md)。做了什么、否决了什么、还有哪些问题和新方向，见 [项目进展摘要](docs/项目进展摘要.md)（含系统思路图）。先看 [代码分工清单](docs/代码分工.md)：它列出每个文件负责什么、输入输出是什么、由谁调用。每份保留源码开头也有中文职责注释。

## 使用

依赖为 `E:\Processing` 中的Processing 4.5.7与自带JDK。正常仿真不需要Python、PyTorch或老师的模板目录。

窗口：空格暂停，R换随机小车起点，＋/－调倍速，S截图。停车标记位于场地中心，默认3米；场地尺寸只给环境，模型不知道真实起点与目标坐标。

窗口底部新增三个控件：**1～4米尺寸选择**、**随机停车框开关**、**趣味地图开关**。两个开关默认关闭，普通模式仍是矩形场地和中心停车框。

打开趣味地图后自动暂停。选择“外边界”或“内部墙”，再选手绘、圆形、椭圆、矩形或直线，在地图上按住鼠标拖动。外边界自动闭合；直线工具用于内部墙，圆/椭圆/矩形也可作为封闭墙圈。手绘支持不自交的凹形与不规则轮廓。

点击“应用地图并运行”开始，地图保存到`configs/FUN_MAP.json`。可撤销、清空墙、重置或再次编辑。关闭趣味地图会恢复普通矩形并保留草稿；关闭随机框则恢复中心停车框。尺寸和开关变化会新开一局；编辑中的变化只在应用时生效。

若墙挡住中心停车框，打开随机框或改地图后再应用。地图空间不足、外边界自交或墙线穿出边界时会提示原因，保留之前的运行。起点只在能与停车框连通、能放下小车的区域生成。

```powershell
# 2米场地
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1 -Size 2
# 编译并验收
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -WithChecks
python .\scripts\verify.py
```

验收核对模型哈希、方向约束、64个完整场景与当前参考、两次用户越线故障回归、真实启动与保存记录。所有开关都从CURRENT_SEARCH.json读取，历史参考保留。

比较搜索质量（找到时间、覆盖效率、平行重复、越线）用 `experiments/search_coverage.py`，按场景配对比较用 `experiments/compare_search.py`（搜索阶段）和 `experiments/compare_parking.py`（找到黑框后的局部停车）；生成调参或确认场景用 `experiments/make_tuning_scenes.py`。这些实验脚本不读取配置里的新开关，不加 `-D` 时即原方案，便于对照。

训练另用 `experiments/train_boundary_motion.py`；依赖在 `E:\SEMTM0043\ProjectTools\RepeatableParking\pydeps`，训练结果写到 `experiments/outputs`，不会覆盖运行权重。实验数据与验收结果分别在 `experiments/data`、`experiments/results`。

## 当前限制

每次触边仍有约0.25秒轮子越线，主要来自刹车惯性：传感器只在中心前约45毫米。原固定64场景64/64停车、0场景重心或双轮心越界，最深单轮越线约3厘米，不能保证真桌沿安全。倒车只沿“走过的格子”、离边距离按灰色格子计算，都依赖里程计；仿真8米内误差约4毫米，实车需先标定。未做实车验证。旧的条件触边动作说明见 [触边运动优化报告](docs/触边运动优化报告.md)。

“找到黑框后局部停车超时”（靠边目标的入口点站不进去）已由入口自适应修正并设为默认。

趣味地图是额外实验模式。圆/椭圆按96段边界模拟，墙线有实际传感器响应与碰撞限制，不只是画面装饰。趣味模式的画线边界和墙不可穿透；碰撞限制属于环境，并不表示模型已经学会凹形地图或复杂避障。

2026-10-14已修正多次触墙后的错误直边记忆：趣味模式不再把多次触碰合成全局直线，也不再用凸包填满凹形空间。保留访问过的区域和重复路径记忆；触边方向按当前传感器及最近2秒、240毫米内的局部障碍点筛选，子目标最多120/240毫米。局部点会过期，不会永远划掉整片地图。单轮动作若400毫秒没有编码器进展，回退到制动后直接转向。

局部筛选仍不是完整地图导航或轮子轨迹安全证明。三个实际失败场景回放中，1米与3米场景现已停车；4米场景在600秒离线测试预算内继续探索、未停车。普通模式保留原直边和凸包处理，64个参考场景仍逐项一致，两份网络权重未改。详见[复杂地图修正记录](experiments/results/local_boundaries_20261014/summary.json)。
